# Security policy

Abralo is an early preview. It has not had an independent security audit, and its local agent execution can read files and run commands according to the selected provider's permission controls. Do not use it with sensitive data or on a shared computer.

Please do not post suspected vulnerabilities, secrets, private files, workspace backups, or unreviewed logs in a public issue. If GitHub's **Report a vulnerability** option is available in the repository's Security tab, use it to send a private report.

At the 5 October 2026 repository review, GitHub private vulnerability reporting was disabled. Enabling and verifying that route is an outstanding launch requirement. Until it is available, ask the repository owner for a private reporting route without including exploit details in public. Do not assume an ordinary GitHub issue is private.

Include the affected version or commit, operating system, concise reproduction steps using disposable data, and the impact you observed. Redact account identifiers, tokens, personal data, and customer or employer information.

There is no guaranteed response time or supported-version commitment during this preview.
