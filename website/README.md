# Abralo website

Source for abralo.com. The homepage explains lasting goals and links to current release status. Run with Node 22+ using `npm install` and `npm start`.

Preview availability must reflect actual release checks. Do not turn a build target into a supported download before acceptance. The example goal on the homepage is illustrative.

The trial form sends requests to Chris through the existing Resend integration. Configure mail credentials in the hosting environment; do not commit them.
