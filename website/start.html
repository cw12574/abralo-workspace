YOUR FIRST TASK / v0.1.3-preview

A small start.
A useful result.

Install the preview, connect one agent, and try a task you can easily check.

This is an early, unsigned preview. Setup currently includes a terminal command. Use your own provider account; provider subscriptions or API charges are separate.

01. Download the right package.

Choose your operating system and CPU on the official release page. On a Mac, Apple menu → About This Mac tells you whether you have Apple silicon or Intel.

Download the matching .tar.gz package and SHA256SUMS. The files called “Source code” are for developers and do not include the packaged application.

Check the download’s checksum

Run the appropriate command in your download folder, replacing the filename with your package. Compare the full result with the matching line in SHA256SUMS.

Windows PowerShell:

Get-FileHash .\abralo-windows-x64.tar.gz -Algorithm SHA256

macOS:

shasum -a 256 abralo-macos-arm64.tar.gz

Linux:

sha256sum abralo-linux-x64.tar.gz

A checksum confirms file integrity; it does not verify the publisher.

02. Extract and install.

Extract the .tar.gz archive. Open the resulting package directory that contains release.json, runtime/, and scripts/. You do not need to install Node or run a build.

WindowsmacOSLinux

Windows x64

In PowerShell, you can extract the downloaded archive with:

tar -xzf .\abralo-windows-x64.tar.gz

Open the extracted package folder in PowerShell, then run:

.\scripts\install-windows.ps1 -ReleaseDirectory .

Open Agent Workspace from the Start menu. Administrator rights are not required.

macOS

Extract the archive in Finder. In Terminal, type cd , drag the extracted package folder into the window, and press Return. Then run: 

./runtime/node scripts/install-posix.mjs

Open Agent Workspace.app from your home folder’s Applications directory.

Linux x64

Extract the archive, open a terminal in the package folder, and run:

./runtime/node scripts/install-posix.mjs

Open Agent Workspace from your application menu. Do not use sudo.

Windows and macOS may show security warnings because the preview is unsigned. If installation is blocked, use the detailed installation and trust guidance. Do not disable system security protection.

03. Connect one agent.

Open Abralo, enter your name, and choose a provider for Chief of Staff. Use the provider’s sign-in screen; never paste credentials into a conversation. Check the connection before continuing.

The recorded build uses Codex. OpenCode requires a connected provider and model selection. Read the provider limitations before choosing Claude Code.

An objective can be a rough outcome; you can select a project folder later.

04. Ask for something you can check.

Create a disposable folder with a short notes.txt file. Choose Ask in the agent’s settings, select that folder in the conversation, and try:

Read notes.txt and draft a short README in this folder. Use only those notes, do not browse or install anything, and show me what you changed.

Review the result. Ask for one small revision. Then close and reopen the app and find the conversation again.

When that works, create a project room and give another agent a specific review task. You can start with one provider; you do not need accounts with every provider.

If something gets in the way.

Note your OS, package version, the last successful step, and the exact error. Report the issue without sharing passwords, sign-in codes, private prompts, or unredacted logs.

The recovery guide covers stuck tasks, restarting, and removing the preview while keeping your data.
